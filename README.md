# Manage Shipment

ERPNext v16 application for managing domestic shipments, courier providers, tracking events, delivery exceptions, follow-ups, and shipment dashboards.

## Module

**Manage Shipment**

## Planned capabilities

- Courier Service Provider master
- Shipment/AWB tracking
- Normalized shipment statuses across providers
- Detailed tracking event timeline
- Courier-wise and status-wise dashboard filters
- Follow-up and exception management
- No-movement detection
- ERPNext document references
- Automatic scheduled tracking
- Bulk tracking
- Provider adapters for Delhivery, DTDC, Trackon, Shree Maruti, Professional Couriers, Anjani and additional providers
- Responsive dashboard modeled on the approved shipment-tracking reference design

## Compatibility

- Frappe Framework 16
- ERPNext 16

Initial development.
